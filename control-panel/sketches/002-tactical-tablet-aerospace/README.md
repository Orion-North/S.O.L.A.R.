## Variant: Tactical Tablet HUD // Aerospace Telemetry Theme

### Design Stance
Handheld field operations interface optimized for tablet screens and touch control. Merges the thumb-cluster tactical layout with the Aerospace Telemetry color palette (`#090d13` obsidian slate, `#1e293b` bezel, `#38bdf8` cyan, `#10b981` radar emerald, `#f59e0b` amber, `#ef4444` crimson).

### Key Choices
- **Touch Ergonomics**: Dual bottom thumb zones — analog pointer-driven vector joystick on the bottom-left with normalized directional output, and 4-button quick-action macro bank (STAND, TURTLE, SIT, RECOVER) on the bottom-right.
- **Oversized Safety Interlock**: Prominent guarded E-Stop button with full-screen crimson warning flash and instant motor disarm.
- **HUD Overlay**: Full-bleed optical camera background with technical reticle, live heading compass tape, and attitude telemetry pill displays.
- **Gait Awareness**: Real-time 4-point foot contact phase pills (FL, FR, BL, BR) displaying stance vs swing timing during locomotion.
- **Gait Cadence Slider**: Direct on-screen tuning for step frequency (40ms - 300ms cycle timing).

### Best For
Field trials, mobile handheld robot piloting, obstacle navigation, and tablet ground control station deployments.
